🏢 细分领域动态

NVIDIA：Vera时代拉开帷幕，COMPUTEX N1/N1X箭在弦上

NVIDIA 5月20日发布FY2027 Q1财报：营收$81.62B（+85% YoY），数据中心$75.2B（+92% YoY，占比92%），Q2指引$91.0B（±2%）——再次碾压华尔街$86.8B预期。Jensen Huang在电话会上给出三个核心叙事：

1. Vera CPU正式出货：5月18日首批Vera CPU交付OpenAI/Anthropic/SpaceXAI/Oracle Cloud，88核自研Olympus核心、1.2TB/s内存带宽、50%单核性能提升。Vera是NVIDIA开辟的$2000亿新CPU市场，Jensen预计FY2027年内贡献$200亿营收（独立于$1万亿Blackwell+Rubin目标）

2. Vera Rubin六芯片平台进入全速量产：Vera CPU + Rubin GPU + NVLink 6 + ConnectX-9 + BlueField-4 + Spectrum-X，NVL72单柜含36颗Vera CPU + 72颗Rubin GPU，近200万个零件、涉及150家台湾供应链伙伴。Jensen上周亲赴台积电台中和CC.Wei敲定CoWoS产能分配，这是"台湾历史上最大的产品量产"——Huang原话

3. COMPUTEX 2026（今日！）N1/N1X ARM笔记本芯片发布：微软/NVIDIA/ARM三方同日发推"A New Era of PC"，定位台北音乐中心坐标。N1X规格已基本确认——20核ARM CPU（10+10，联发科设计） + 6144 CUDA核Blackwell GPU（RTX 5070级别） + LPDDR5X统一内存，45-80W，TSMC 3nm N3E。N1为18-45W低功耗版，12核/10核两种配置。Dell XPS首发，Lenevo Legion 7/Yoga/ASUS ProArt/MSI Surface均已备货，预计2026年底前上市

竞争影响： NVIDIA N1X的发布意味着Qualcomm Snapdragon X Elite/X2将不再独享Windows on Arm授权。更致命的是N1X内置了完整的CUDA生态和RTX 5070级GPU——这是游戏玩家的终极武器，直接威胁Intel/AMD x86笔记本和Apple M系列。与联发科的联合开发模式（联发科设计CPU+基带，NVIDIA提供GPU+CUDA）开辟了崭新的"合纵连横"模式。

存储：DDR4创$20历史新高，Micron FQ3（6/24）成多空分水岭

价格追踪： DDR4 8Gb基准芯片5月均价$20/颗（+25% MoM），DRAMeXchange自2016年追踪以来最高。Q2 DRAM合约价+58-63%（Q1 +90-95%）、NAND +70-75%（首次超过DRAM）。Enterprise SSD成为最大NAND应用类别，首次超过消费级存储。

结构性转变（这才是核心论点）： UBS指出，当前存储周期与历史周期有本质性差异——

长协（LTA）占比快速提升：三星30%、Micron 20%、SK海力士18%的DRAM已进入LTA
典型LTA结构：3年固定价+2年延期期权，或"2年固定+3年延期"
服务器DDR5约60-70%已通过LTA锁定
预计2027年行业20-30% DRAM量、约20% NAND量转为LTA

这意味着存储正从"先产后卖"的commodity模式切换为"先单后产"的foundry模式——储盈利稳定性前所未有。但这同样意味着：价格下跌周期可能比过去更慢、更平——但绝不会消失。 Micron CEO表示"只能满足客户50-65%的需求请求"。

Micron FQ3（6/24）关键催化剂： 指引收入$33.5B、毛利率~81%、non-GAAP EPS $19.15。共识预期EPS $19.62，收入$34.26B。Micron股价一年内+848%，市值突破$1T。6/24电话会的HBM/DRAM合约定价comment是判断整个存储上行周期拐点的唯一关键信号。

竞争影响： SK海力士HBM市占率50-62%领先，2026年全部产能已售罄。三星是最大"变数"——HBM4能否在2H26通过NVIDIA认证是关键。如果三星落后，SK海力士溢价将维持。Micron是最干净的US-listed纯存储标的，但240%+ YTD涨幅已包含大量乐观预期。

台积电：CoWoS良率98%里程碑，股东会（6/4）聚焦涨价可能性

台积电5/14技术研讨会重磅更新：

CoWoS良率突破98%：5.5-reticle版本已量产，支持12颗HBM。未来Roadmap：2028年14-reticle/20 HBM、2029年>14-reticle/24 HBM
产能： 2022-2027 CoWoS CAGR >80%，2026年新建9座晶圆厂/封装设施。月产能从2023年底~15K扩至2026年4月~65K，目标年底120-140K
3nm全满，涨价在即： TrendForce报道2H26可能涨价10-15%，2027年再涨5-10%
全球半导体产值2030年预测上调至$1.5万亿（此前$1万亿）
AI加速器晶圆需求：2022-2026增长11倍

6/4股东会三大焦点：

1. AI需求可见性与3nm/CoWoS定价

2. 董事会扩至12人（应对全球扩张治理）

3. 亚利桑那量产进度+员工利润分享

NVIDIA已预占CoWoS约60%产能（~59.5万片），Broadcom约15%、AMD约11%。台积电的产能分配实际上决定了全球AI芯片的供应节奏。

竞争影响： Intel Foundry在先进封装上尚未追上台积电，Samsung 3nm GAA良率仍存质疑。TSMC的2nm N2P产能2026年底目标>6万WPM且已全满——设计厂别无选择。 N2P涨价压力将进一步压缩SoC厂商利润率。

手机SoC：Qualcomm艰难过渡，数据中心初现曙光

Qualcomm FQ2（5/1）： 营收$10.6B（-2.2% YoY），手机收入$6.02B（-13% YoY），QTL稳定。但最关键的叙事变化：

"Qualcomm has secured a definitive agreement to supply custom data center processors to a major hyperscale cloud provider. First shipments scheduled for December 2026."

这是Qualcomm十年来对数据中心的最重要战略回击。基于Nuvia Oryon CPU架构的定制方案，对标AWS Graviton/Google Axion的ARM服务器芯片市场。CFO Palkhiwala在5/19 JPMorgan会议透露三个支柱：1）定制硅（2026年12月）；2）AI推理加速器（研发中）；3）云原生CPU（长期）。12月发货对FY2027是"very material"。

Q3指引疲软： $9.2-10.0B（低于预期$10.2B），中国Android渠道库存仍在去化（存储涨价压制），但公司预计Q3为年内底部、Q4恢复增长。

汽车业务亮点： 年化$50亿收入（+38% YoY），FY2026结束前预期$60亿+。第五代Digital Chassis平台提供3x CPU/3x GPU/12x NPU性能提升。

竞争影响： Qualcomm的AI叙事终于有了DN（数据中心）维度，不再是纯掌上终端的故事。但QCOM在PC端即将面临NVIDIA N1X+微软+ARM的联军攻击，手机端面临联发科Dimensity 9600 2nm SoC（9月）竞争，两头受压格局未变。

MediaTek：Dimensity矩阵持续扩张，N1X联合开发引关注

MediaTek 5月发布两款新品：

Dimensity 8550（4nm N4P）：LLM Booster + Gemini Nano V3支持，Honor 600 Pro首发
Dimensity 7500（4nm）：首颗搭载ARM全新C1核心架构的移动SoC，4xC1 Pro 2.6GHz + 4xC1 Nano 2.0GHz。视频转码+68%、文件传输+40%、能效+5-9%

Dimensity 9600（2nm）预计9月登场，将与Qualcomm Snapdragon 8 Elite Gen 6同步竞争。DCS爆料：2+3+3全大核架构，单核性能可能挑战Apple A20，GPU支持原生帧插值和光线追踪。

最大战略卡位： 与NVIDIA联合开发N1/N1X笔记本芯片CPU部分——MTK提供ARM CPU设计、基带和SoC集成能力，NVIDIA提供Blackwell GPU和CUDA生态。这种"各取所长"的合作模式可能成为手机SoC厂商进入PC市场的蓝本。

Broadcom/Marvell：定制ASIC双寡头，差异化加速

Broadcom（AVGO $446.77）： FQ1 2026 AI收入$84亿（+106% YoY），Q2指引$107亿。$730亿AI积压订单锁定至FY2027 $1000亿目标。关键进展：

Google 2031年长期协议正式化—— Broadcom为Google定制TPU至2031年
新增Apple + Anthropic + FuriosaAI 进入XPU客户名单
首颗2nm Compute SoC：4颗N2计算Die + 1颗I/O Die + 6颗HBM4模块
Tomahawk 6（102.4 Tbps）量产出货，Jericho 4（51.2 Tbps）已发货
Meta MTIA 500预告：30 PFLOPS MXFP4、384-512GB HBM、27.6TB/s带宽——性能超过NVDA/AMD同期产品
AI收入占总收入65%

Marvell（MRVL $205.00）： FY2026 AI ASIC营收预估$11亿（Broadcom约$120亿——8倍差距）。AWS Trainium和Microsoft Maia两大客户均处于"追赶"模式。Computex 6/2主题演讲：CEO Matt Murphy聚焦AI互联瓶颈。Google已接触Marvell开发MPU和下一代TPU变体——但这是2028年之后的收入事件。

竞争影响： Broadcom的ASIC模式（78.6%毛利率+资本轻型）正在证明比NVIDIA的垂直整合模式更优——尽管NVIDIA的$1万亿Blackwell/Rubin是一个不同量级的目标。Broadcom捕获AI基建的经济价值，NVIDIA捕获市场想象——两者可以同时成立。

苹果：A20 Pro 2nm首秀，iPhone 18 Pro九月登场

Apple A20 Pro芯片预期规格：

TSMC N2 2nm制程：CPU性能+15%，能效+30%
首次采用Wafer-Level Multi-Chip Module（WMCM）：SoC与DRAM在晶圆级直接集成，无需interposer
RAM升级至12GB
9月iPhone 18 Pro/Pro Max发布
基础款iPhone 18推迟至2027年春季（存储器成本压力导致分化策略）

iPhone 18 Pro Max电池预计5,100-5,200mAh（史上最大），搭配A20 Pro的30%能效提升，续航表现值得期待。

竞争影响： Apple的2nm A20 Pro将进一步提升iPhone端侧AI能力。对比之下，Qualcomm和MediaTek选择更贵的TSMC N2P节点追赶。Apple再次用"旧节点+极致架构优化"策略对抗对手的"新节点+高成本"路线。

🔗 传导链追踪

传导链一：存储结构性涨价 + AI芯片扩产博弈



AI数据中心需求加速（2025Q3起）


  → HBM产能2025Q4满载，SK海力士售罄至2027年底


    → DRAM合约价Q1 2026 +90-95%（历史峰值区间）


      → DDR4 8Gb突破$20历史新高（2026年5月）


        → 消费电子BOM大涨，存储BOM占比翻倍


          → 中国手机OEM下调全年出货目标（小米/OPPO/vivo）


            → SoC厂（高通/联发科）削减投片10-15%


              → 存储厂改变商业模型：从commodity→LTA长协模式


                → 三星/SK海力士/Micron优先扩产HBM，牺牲消费级产能


                  → 存储从"周期性"切换为"结构性紧张"（UBS论点）


                    → ⚠️ Micron 6/24财报：HBM合约定价决定多空


                      → 新产能投入（Micron Idaho/三星Texas/SK Indiana）：2027年底~2028

关键观察点： 本次存储周期与历史周期的核心差异在于结构性产能再分配——三大厂已将大量wafer产能从消费级转向HBM/服务器级，消费级DRAM的"永久性"供给收缩是基础性的供需关系变化，而非周期性的供应控制。 这意味着：即使AI需求降温，消费级内存价格也很难回落到2024年水平。

传导链二：NVIDIA N1X + Windows on ARM = PC生态重塑



NVIDIA FY2027 Q1业绩超预期（$81.6B, +85% YoY）


  → Vera CPU交付OpenAI/Anthropic/SpaceXAI（5/18）


    → Vera Rubin平台进入全速量产（6芯片系统）


      → Jensen访台敲定TSMC CoWoS产能分配（5/23）


        → COMPUTEX 2026 发布N1/N1X（6/1）


          → NVIDIA首次拥有消费级CPU产品线


            → 联发科设计CPU+基带 / NVIDIA提供Blackwell GPU+CUDA


              → Windows on Arm生态获得第二家SoC供应商（打破Qualcomm独占）


                → Dell/ASUS/Lenovo/MSI笔记本首发（2026Q4）


                  → x86笔记本市场（Intel/AMD）承受2027年结构性压力


                    → Qualcomm Snapdragon C/X系列面临前后夹击

关键观察点： NVIDIA N1X的战略意义不仅在于"又一款ARM PC芯片"——它是第一款内置CUDA核心和RTX 5070显卡的笔记本SoC。这意味着在Windows生态中，首次出现"一台笔记本=一台游戏PC"的可能性。Apple M系列的"统一内存+高集成度"优势被NVIDIA的CUDA+RTX生态反超。这个产品的最大风险是功耗和散热——45-80W在ARM笔记本中偏高。
