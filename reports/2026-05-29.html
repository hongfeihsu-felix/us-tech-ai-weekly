🏢 细分领域动态

NVIDIA（NVDA · $214.25）：Parabolic Demand确认，Vera Rubin开启CPU革命

NVIDIA在5月20日发布FY27 Q1财报，各项数据全面超预期：

营收$81.6B（+85% YoY，+20% QoQ），连续三个季度同比加速
数据中心$75.2B（+92% YoY），Blackwell GPU需求"已呈抛物线式增长"
Non-GAAP EPS $1.87（vs 共识$1.76），毛利率74.9%
Q2指引$91B（vs 共识$87.3B），但剔除$8B的H20中国禁令影响
$80B新增回购授权，季度股息从$0.01提高至$0.25

Jensen Huang在Computex 2026上宣布：

"Taiwan is the epicenter of the AI revolution."

>

NVIDIA每年在台支出将扩大至~$150B（4-5年前仅$10-15B），Vera Rubin系统含近200万个零件、通过150家台系合作伙伴完成。

Vera CPU首次基准测试曝光（Phoronix）：88核Olympus（Arm架构）CPU比Grace快63%，比AMD EPYC 9575F快10%，比Intel Xeon 6980P快55%。CFO Colette Kress称Vera CPU开辟$200B新TAM，FY27预计CPU收入~$20B。首批Vera机架已交付OpenAI、SpaceX、Anthropic、Oracle。

竞争影响：NVIDIA同时掌控GPU（Blackwell/Vera Rubin）、CPU（Vera/NVLink交换机），对AMD/Intel形成"CPU+GPU+网络"全套方案竞争。Motley Fool评论"Checkmate"风险真实存在。

SK海力士/美光：LTA框架确立，存储从周期股到成长股的估值切换

本周最重磅的行业事件是存储器长协（LTA）框架的全面确立：

UBS分析师Timothy Arcuri将美光目标价从$535三倍上调至$1,625（华尔街最高），核心论据：LTA将20-30%的DRAM出货转化为3-5年期固定量价合约，叠加预付定金机制，存储器盈利模式从"周期性峰值→低谷"转变为"类公用事业稳定盈利"
Barclays将美光目标价从$675上调至$1,175（Overweight），强调Strategic Customer Agreements的历史性意义
UBS估算：即使温和下行周期，美光EPS仍可维持在$100+（2028-2029），Forward PE从~5x重构至~15x（参考NVIDIA的NTM PE）
SK海力士年内暴涨~200%，Q1营业利润率72%创历史，HBM产能被预订至2027年底

存储供需最新数据（Counterpoint Research）：全球DRAM Q1营收$97B（+80% QoQ / +260% YoY），Q2再涨约50%（含HBM和常规DRAM）。三星市占扩大（Counterpoint称三星领先SK海力士/美光），但CXMT（长鑫存储）收入翻7倍，市占达8%，将成为全球第四大DRAM供应商。

竞争格局重置：传统"现产现卖"模式终结，代之以"先下单再生产"的类Foundry模式。UBS预计LTA将覆盖20-30%的DRAM总量和约20%的NAND。高带宽存储优先分配，消费级DRAM/NAND持续受挤压。

风险：AI自定义XPU比例上升可能导致毛利率承压150-200bps（FY28）。

🔗 传导链追踪

传导链一：AI需求 → 存储暴涨 → 终端涨价 → 产能追赶 → 周期顶点预期

NVIDIA Q1财报确认需求"抛物线式增长"（2026年5月） │ → HBM全年售罄，SK海力士/三星/美光LTA锁定3-5年产能（已发生） │ → DRAM Q1合约价+90-95% QoQ已达峰值，Q2再+58-63%（仍在高位上涨） │ → 消费电子BOM承压：手机SoC厂削减投片-10~15%（2026Q1已确认） │ → DDR5合约价~$13/GB，Spot高达$25-27/GB（创历史） │ → 传统定价±10%季度波动带完全消失，改为"后结算定价"模式 │ → 中国OEM（小米/OPPO/vivo/传音）利润受损，出货目标持续下修 │ → 三星/SK海力士/美光新产能2027H2陆续开出 │ → UBS预期：DRAM短缺将延续到2028Q2，NAND到2027Q4（⚠️供需拐点大幅后移）

关键变化：LTA框架的确立从根本上改变了传统存储器周期的时间线。UBS认为即便2028年出现温和下行，EPS仍可维持在$100+——这在此前的周期中是不可能实现的。存储行业的估值逻辑正从"5x PE的周期性血拼"转向"15x PE的AI基础设施成长股"。

传导链二：AI训练 → Agentic AI推理 → CPU需求爆发 → NVDA跨界CPU

Agentic AI推理需求爆发（2026H1加速） │ → CPU/GPU比例从1:8转向1:4（Intel CEO Pat Gelsinger确认） │ → 趋势继续向接近1:1迈进（推理场景CPU主导） │ → NVIDIA Vera CPU（88核Olympus Arm架构）正式出货 │ → 基准测试：快Grace 63%、快AMD EPYC 10%、快Intel Xeon 55% │ → CFO Kress：Vera CPU打开$200B新TAM，FY27预计收入$20B │ → AMD/Intel数据中心CPU面临前所未有的跨界竞争 │ → 下一代AMD EPYC "Venice"（2nm）/ Intel "Diamond Rapids"已备战

关键变化：NVIDIA首次以"CPU供应商"身份出现，与训练/推理GPU形成垂直整合方案。AMD 2nm EPYC Venice已开始量产，Intel Diamond Rapids在路——2026H2至2027H1的CPU大战将是AI基础设施投资的核心看点。

传导链三：先进封装瓶颈 → CoWoS扩产 → 良率突破 → ASIC定制化浪潮

CoWoS产能：35K wpm（2024末） → ~120K wpm（2026末扩产~4倍） │ → CoWoS良率已达98%（关键里程碑：降低单颗AI芯片封装成本） │ → CoWoS光罩尺寸：5.5x（2026） → 9.5x（2027）——更多chiplet封装 │ → NVIDIA预承诺>50%的CoWoS产能至2027年 │ → AMD/Google/Amazon/AWS争夺剩余产能 │ → Broadcom/OpenAI XPU（定制ASIC）需求爆发 │ → 瓶颈从封装转向HBM（Lisa Su公开确认） │ → HBM短缺预计延续至2030年（SK集团会长Chey Tae-won表态）

关键变化：产业链瓶颈从CoWoS封装→HBM存储转移，AI芯片设计商的竞争焦点正从"谁能设计更快的芯片"转向"谁能锁定更多存储/封装产能"——AMD Lisa Su访韩会见三星李在镕、黄仁勋与台积电魏哲家"世纪晚餐"，都是这一逻辑的体现。

⚠️ 风险因素

🔴 高可能：存储器LTA框架不及预期——虽然LTA在改变行业结构，但历史上有2017年的前车之鉴（Google的TurboQuant算法导致单日$900亿市值蒸发）。若2027年消费需求超预期下行或扩产时间点集中，LTA价格锁定的保护作用可能有限。概率：~55%。影响：美光/SK海力士PE回归至~8x，下行30-40%
🔴 高可能：NVIDIA H20中国禁令造成$8B/季营收缺口——Jensen Huang在财报会上明确表示"$50B中国市场已对美企实质性关闭"。若Trump进一步收紧对华半导体出口管制（7月国家安全关税审查），NVDA中国收入可能永久性归零。概率：~60%。影响：NVDA EPS下修~10%，目标价下调至~$260
